Guía de ejemplo

Así viaja un dato desde la tienda hasta Google Analytics

Seguimos a un cliente de prueba que compra el Plan mensual. En cada paso, la página escribe un evento en el dataLayer. Google Tag Manager lee ese evento y lo envía a Google Analytics 4. Todos los datos son ficticios.

  1. 1. Ve el catálogo

    El cliente abre el catálogo. La página muestra los productos y registra qué se ve en la lista.

    dataLayer.push({ event: 'view_item_list', ecommerce: { item_list_name: 'Catalogo', items: [...] } });

  2. 2. Abre un producto

    Entra a el detalle del Plan mensual. Se registra la vista del producto.

    dataLayer.push({ event: 'view_item', ecommerce: { currency: 'USD', value: 59.90, items: [{ item_id: 'SKU-001', item_name: 'Plan mensual', price: 59.90, quantity: 1 }] } });

    Al pulsar Agregar al carrito se envía add_to_cart.

  3. 3. Revisa el carrito

    En el carrito el cliente puede subir o bajar cantidades y quitar productos. Cada cambio envía add_to_cart o remove_from_cart, y al cargar la página se envía view_cart.

  4. 4. Inicia el pago

    Al entrar al checkout se envía begin_checkout con el valor del carrito. Luego, el cliente elige el envío y el pago, y cada elección se registra.

    dataLayer.push({ event: 'add_shipping_info', ecommerce: { currency: 'USD', value: 107.90, shipping_tier: 'express', items: [...] } });

  5. 5. Confirma el pedido

    El botón lleva a la página de gracias. Ahí se envía la compra completa con un transaction_id único y se vacía el carrito, para que recargar la página no cuente la venta dos veces.

    dataLayer.push({ event: 'purchase', ecommerce: { transaction_id: 'T-1760000000000', currency: 'USD', value: 107.90, shipping: 12.00, items: [...] } });

  6. 6. Lo que ve Google Analytics 4

    GA4 agrupa los eventos en el embudo de compra: lista de productos, vista, carrito, inicio de pago y compra. Con transaction_id puedes cruzar cada venta con tu sistema de pedidos.

  7. 7. Lo que configuras en Google Tag Manager

    Crea una variable de capa de datos para ecommerce.items y otra para ecommerce.value. Luego, una etiqueta de GA4 por cada evento, y valida todo en el modo Vista previa antes de publicar.

¿Listo para probarlo? Empieza en el catálogo.
